# Pirate Cats

Pirate cats is an interactive 2D point and click game where you find yourself on a boat with cats in the middle of the ocean?!
Help the cats solve various puzzles to uncover map pieces hiding throughout the boat and set sail towards the ultimate treasure!

Creation:
- Made in Godot 4.7

Specials:
- Dialogue/Skip Text
- Different Minigames
- Cool Cats


Controls:
- Mouse - Click
- Space bar- shoot/skip text
- Arrow Keys - move cannon

Credits:
- SFX created by us
- Background Music from Pixabay
- Assets created in Figma

Good luck fellow adventurers, and find that treasure!
